# Digital Signal Processing Toolkit

A Python-based project that implements fundamental Digital Signal Processing (DSP) operations and visualizes digital signals using Matplotlib.

## Features

- Discrete-time signal generation
- Exponential signal generation
- Moving average filtering
- Convolution
- Cross-correlation
- Fourier Transform
- Sampling and quantization
- Signal visualization using Matplotlib

## Technologies Used

- Python
- Matplotlib
- SciPy

## Project Structure

| File | Description |
|---|---|
| `main.py` | Main project entry point |
| `Elementary_Discrete_Time_Signals.py` | Discrete-time signal operations |
| `exponentialSignals.py` | Exponential signal generation |
| `moving_average_filter.py` | Moving average filtering |
| `Convolution.py` | Convolution operations |
| `cross_correlation.py` | Cross-correlation operations |
| `Fourier.py` | Fourier Transform |
| `sampling_quantization.py` | Sampling and quantization |
| `Z.py` | Z-related operations |

## Installation

Clone the repository:

```bash
git clone https://github.com/Sara1brahim/Digital-Signal-Processing.git
cd Digital-Signal-Processing
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

## Run the Project

```bash
python main.py
```
